# Back to the Burrow

<img width="1102" height="729" alt="Screenshot 2026-11-15 161707" src="https://github.com/user-attachments/assets/79d2180e-90c1-44e1-b8e8-5154bc3a41c9" />

Play as a bunny who needs to get to the carrot and bounce back to the burrow before night falls! You'll need to traverse the terrain by day, and return as the sun sets...

**Controls:** Mouse and Keyboard

This game was created for **[Hack Club Haven](https://haven.hackclub.com/)​** in a team of 3 people. We used [Godot](https://godotengine.org/) for game development, [ibisPaint X](https://ibispaint.com/?lang=en-US) for art, and [FL Studio](https://www.image-line.com/) for music.
